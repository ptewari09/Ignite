# Frontend workspace

Reserved for React, TypeScript, Vite and Tailwind CSS. No UI, package manifest or dependencies have been scaffolded.

- `src/api`: future browser calls to the backend.
- `src/components`: reusable interface pieces such as tables and evidence panels.
- `src/pages`: upload, reconciliation and report-review screens.
- `src/types`: TypeScript contracts corresponding to API responses.
- `tests`: important user interactions, once the UI exists.

Start frontend implementation after ingestion and reconciliation contracts are verified.
